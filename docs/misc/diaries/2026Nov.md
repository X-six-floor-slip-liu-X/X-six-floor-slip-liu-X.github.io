# 2026 十一月日记

依旧美食测评。

## 11.1

今天有班级团建。

早上八点过起来吃了早饭（东园一楼海带豆腐面）然后九点半和同学拼车过去，aa 下来一个人只要 $3$ 块多。

然后上午打了会台球，然后打了会桌游（卡卡颂和三国杀）就点外卖吃饭，点了个肘子加米饭，其实还不错，而且价格也挺合适的，可惜华科这边点不了，$8$ 分。

下午打了下明日方舟新活动然后继续打桌游（UNO），时间就差不多了，于是又拼车回来。

那个傻逼司机跟没学过科目一一样，一路违章就不提了，他妈的下雨的时候让我们把窗户开着说不然会起雾。狗日的他驾照怎么拿到的，真该查查了。

晚上回来在东教工食堂吃的快餐，味道还行，比较实惠，给到 $6.5$。

然后晚上组会。分享了《火山的女儿》和《空洞骑士》。

## 11.2

我有早八。

早上韵酒热干面，我没钱了真得吃这个了。

中午东园三楼，人爆多，我之前似乎都恰好碰到人少的时候了，这次好吃的基本都被打走了，唉唉，$7$ 分。

下午韵酒卤汁饭窗口，黑鸭卤汁饭，是武汉那种辣卤，还不赖，$7.5$ 分。

晚上在社团活动室写线代和微积分作业，然后写了两篇英语作文。

## 11.3

我还有早八。

早上东园一楼酸菜肉丝面，比韵酒好吃，$6.5$ 分。

上午两节水课一直做微积分作业，一直到我自学的范围。

然后看到班长在用“不背单词”背单词，感觉很有用遂自己下了一个。

中午东园一楼烤鸡腿鲍汁捞饭。

哎哟感觉一直在吃一样的东西。

下午工图课感触良多，每一节工图课都坚定了我转专业的想法。

晚上学二二楼黄焖小酥肉，$5$ 分。唉不该贪便宜的，肉太少了，纯骗小孩的。

然后去联创办公室，先把工图作业做完了，然后想看微积分书发现带错书了。哎哟为什么军事理论的书要长得和微积分一样啊。

然后装了 SolidWorks，又 New 了一个 github 仓库以备以后存新人任务的资料。

然后居然就十点钟了，唉唉。

## 11.4

疯狂星期三之一柱擎天，早八到晚十要不是没作业还以为在上高中。

早上韵酒的馄饨。要是不知道吃什么就吃这个了，便宜有肉又好吃。

上午线代课依旧上课时间把作业做完，发现我高中自学的完全就是一坨实史，还得是大学成体系地学才能学会。

午饭点的外卖，一家店铺名字里面有“公瑾爆蛋”的店。报吃，$4$ 分。

午觉没睡好下午微积分差点睡着，唉唉。

倒是考试时间出来了，十一月十五号早上八点半到十一点，考到洛必达的上一节。

晚饭韵酒咖喱鸡肉饭，还行 $6.5$ 分。

晚上准备看点微积分。

好的在思政课上看完了一节，然后开始写练习册。

## 11.5

终于没有早八了。

早上起来吃的韵酒番茄鸡蛋面，然后就去社团办公室待了一会，打了会游戏然后把没做完的练习册做完了。

然后中国语文，问到了什么时候怎么交作业，然后把笔记整理到电脑上了。

午饭学一一楼烤鸡腿鲍汁捞饭。

中午直接前往社团办公室睡午觉，下午开始学习 Unity。

晚饭学一一楼快餐，有一个神秘肘子尝了一下，挺贵的说是，味道还行 $6$ 分。

晚上继续学 Unity。感觉今天差不多能把 Unity 客户端怎么操作学会，那估计得周六赶一整天新人任务了。
